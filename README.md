# BroTeam

Десктопное приложение для ежедневной работы команды с несколькими agile-досками Yandex Tracker. Показывает задачи матрицей «участник × статус», собирает сводку за период и хранит черновики, заметки и закладки локально.

Репозиторий: [github.com/ensatum/broteam](https://github.com/ensatum/broteam).

## Что умеет

- Несколько досок в одном окне. У каждой свои колонки, цвет вкладки и состав строк.
- Таблица задач: компактный режим и режим с иконками. Ширина и режим запоминаются по доске.
- Иконки в ячейке: нет ревьюера, нет тестировщика, простой, чужой спринт, обновления. Колонке можно выдать тег «Ревью» или «Тесты», и тогда отсутствие этой роли подсвечивается сильнее.
- Сводка за период по всем включённым доскам. Задача попадает участнику, если в периоде он был исполнителем, ревьюером или тестировщиком, либо сам менял задачу. Пустой исполнитель (часто на досках, где работу делает AI) задачу не отбрасывает.
- Черновики, заметки к задачам, закладки, список изменений с прошлого обновления.
- Настройки подключения к Tracker, участники, доски и колонки, расписание автообновления, импорт и экспорт базы.

## Данные

База лежит в каталоге пользователя и не зависит от каталога сборки:

- Linux: `~/.config/bro-team/`
- macOS: `~/Library/Application Support/bro-team/`
- Windows: `%APPDATA%\bro-team\`

Если базы ещё нет, при первом запуске подхватывается каталог старой установки: `tracker-standup`, `BroTeam` или `BroTracker`.

## Разработка

Нужны Node.js 20+ и npm. Нативный модуль `better-sqlite3` собирается под Electron, не под системный Node.

```bash
npm install
npm run dev
```

Проверка типов: `npm run typecheck`.

## Сборка

Linux (AppImage и deb, каталог `release/`):

```bash
npm run dist:linux
```

macOS с Linux-машины, без подписи Apple. Получаются zip для Intel и Apple Silicon; на Mac при первом запуске — ПКМ → Открыть.

```bash
npm run dist:mac
```

Windows (удобнее на Windows или в CI):

```bash
npm run dist:win
```

Сборка кладёт в пакет только бинарь той системы, для которой он собран. Модуль macOS не попадает в AppImage и наоборот.
